# Maquettes (non publiées)

Dossier de travail pour la refonte de l'interface. Rien ici n'est mis en ligne (seul `app/` l'est).

- `audit/` — étape 1 : audit de l'existant (`AUDIT.md`, planches annotées, captures « avant »).
- `maquettes.html` + `maquettes.css` — étape 2 : maquettes statiques, une seule structure d'écrans en 3 styles.
  Ouvrir `maquettes.html?d=signal`, `?d=carnet` ou `?d=pop` dans un navigateur (mode sombre : celui du système).
  Le fond de carte (`img/carte-toulouse.png`) est une image fixe faite de tuiles OpenStreetMap.
- `directions/` — planches envoyées au propriétaire pour choisir une direction.
